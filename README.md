## Overview

WSSS framework for breast cancer histopathology — achieves semantic segmentation using **only image-level labels**. The pipeline has 3 stages:

1. **Stage 1 — WSSS Training**: Train CAM generation model (UNI encoder + VQ codebooks + text-visual prototypes)
2. **Stage 2 — Pseudo Label Generation**: Generate pseudo segmentation masks via multi-scale CAM fusion
3. **Stage 3 — Segmentation Training**: Train segmentation model (Phikon/SegFormer/CTransPath) on pseudo labels

## Full Pipeline

### Stage 1: WSSS Training (CAM Generation Model)

Train the classification model that learns to generate Class Activation Maps.

```bash
python scripts/train.py --config configs/default.yaml --gpu 0
```

**What it does:**
- Loads UNI ViT-L/16 (frozen) + LoRA adapters
- Trains VQ codebooks + text-visual prototypes
- Multi-scale CAM generation (P1-P4)
- Contrastive learning with FG/BG features
- Saves best checkpoint to `checkpoints/cam/<timestamp>/best_cam.pth`

**Key config** (`configs/default.yaml`):
```yaml
model:
  use_lora: false
  use_vq: true
  use_text_proto: true

train:
  epoch: 8
  samples_per_gpu: 4
  accum_steps: 4
  learning_rate: 5e-5
```

**Output:** `checkpoints/cam/<timestamp>/best_cam.pth`

---

### Stage 2: Pseudo Label Generation

Generate pseudo segmentation masks from the trained CAM model.

```bash
# Generate for training set (used as pseudo labels for Stage 3)
python scripts/inference.py \
    --config configs/default.yaml \
    --checkpoint checkpoints/cam/<timestamp>/best_cam.pth \
    --split train \
    --gpu 0
```

**What it does:**
- Loads trained CAM model
- Generates multi-scale CAMs for each image
- Fuses CAMs: `0.3×CAM2 + 0.3×CAM3 + 0.4×CAM4`
- Saves pseudo masks to `predictions/` as PNG files

**Output:** `predictions/*.png` (pseudo segmentation masks)

---

### Stage 3: Segmentation Training

Train a segmentation model on the pseudo labels from Stage 2.

```bash
python train_seg/train_seg.py
```

**What it does:**
- Loads backbone (Phikon/SegFormer/CTransPath) with LoRA
- Trains on pseudo labels from `predictions/`
- Validates on GT masks from `data/BCSS-WSSS/val/`
- Tests on GT masks from `data/BCSS-WSSS/test/`
- Saves best checkpoint to `checkpoints/seg/best_seg.pth`

**Switch backbone** — edit `train_seg/config.py`:

```yaml
# Option 1: Phikon (pathology pretrained ViT-B) — recommended
model:
  type: phikon
  backbone: owkin/phikon

# Option 2: SegFormer MIT-B3
model:
  type: segformer
  backbone: nvidia/mit-b3

# Option 3: CTransPath (lightweight, pathology pretrained Swin-T)
model:
  type: ctranspath
  backbone: wisdomik/QuiltNet-B-16
```

**Key config** (`train_seg/config.py`):
```yaml
train:
  epochs: 30
  batch_size: 16
  crop_size: 224
  lr: 0.00006
  backbone_lr_scale: 0.1
  warmup_epochs: 3
  ce_weight: 1.0
  dice_weight: 0.5
  use_noise_robust_loss: true
```

**Output:** `checkpoints/seg/best_seg.pth`

## Dataset

Download [BCSS-WSSS](https://bcsegmentation.grand-challenge.org/) and organize:

```
data/BCSS-WSSS/
├── training/          # Training images (*.png, filenames contain class labels: ...[0110]...)
├── val/
│   ├── img/           # Validation images
│   └── mask/          # Ground truth masks
└── test/
    ├── img/           # Test images
    └── mask/          # Ground truth masks
```

**Classes:** TUM (0), STR (1), LYM (2), NEC (3) — BACK is mapped to ignore_index=255.

## Architecture

```
Stage 1: WSSS CAM Model
========================
Input Image (224×224)
    ↓
UNI ViT-L/16 (frozen + LoRA)
    ↓
SFP: P1(56×56) → P2(28×28) → P3(14×14) → P4(7×7)
    ↓
VQ Codebook Quantization (P2-P4)
    ↓
Hybrid Text-Visual Prototypes
    ↓
Multi-Scale CAMs → Fuse: 0.3×CAM2 + 0.3×CAM3 + 0.4×CAM4
    ↓
Pseudo Segmentation Mask

Stage 3: Segmentation Model
============================
Input Image (224×224)
    ↓
Phikon ViT-B / SegFormer / CTransPath (frozen + LoRA)
    ↓
FPN Decoder (multi-scale feature fusion)
    ↓
Segmentation Output (4 classes)
```

| Stage 3 (CTransPath) | Swin-T | 6GB | 8GB+ |
